# lab3-idef0-airline-tickets
Лабораторна робота 3 — моделювання системи продажу авіаквитків у IDEF0

## Тема
CASE-засоби моделювання бізнес-процесів інформаційних систем. Методологія IDEF0.

## Предметна область
Airline Ticket Sales System — система продажу авіаквитків і керування розкладом рейсів.
